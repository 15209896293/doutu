## 二、安装到自己的手机

### 方式 A：微信/QQ 发送（最方便）
1. 电脑登录微信/QQ → 把 APK 文件**发送到「文件传输助手」**或发给自己；
2. 手机微信/QQ 打开文件 → 点右上角「···」→ 选择「**用其他应用打开**」→ 选「文件管理/安装器」；
3. 弹出安装确认 → 点「安装」。

### 方式 B：数据线 + 文件管理
1. USB 数据线连接电脑，手机选「传输文件」；
2. 把 APK 复制到手机「下载」目录；
3. 手机打开「文件管理」→ 找到 APK → 点击安装。

### 安装时的两个确认（必看）
1. **「未知来源/外部来源应用」授权**：首次安装非应用商店的应用，系统会提示"禁止安装未知应用"，点「允许此来源」再装；
2. **「已存在应用」**：手机里已装过旧版豆图（v0.6/v0.9.0 等），直接覆盖安装即可，**不会丢历史作品**（作品存本地文件，覆盖安装保留）。

### 安装完成后
- 桌面出现「豆图」图标 → 点开即可用；
- 换图流程：导入图片 → 裁剪 → 选板型/比例/色卡/预设 → 生成 → 预览/编辑/跟做/导出。

## 四、试用版（24 小时试用 + 激活码）怎么做 —— 需要你提供 2 个配置

试用版代码已全部就绪（试用门卫/激活页/Supabase 网关/Edge Function/测试码生成器），
**只差 Supabase 配置**。步骤：

### 1. 建 Supabase 项目（免费）
1. 打开 <https://supabase.com> → 注册/登录 → New Project（地区选 Singapore/东京，密码记好）；
2. 项目创建后：左侧 **Project Settings → API**，复制两项发给我：
   - **Project URL**（`https://xxxx.supabase.co`）
   - **anon public key**（`eyJ...` 长串）
   我拿到后立刻帮你打包试用版 APK。

### 2. 建表（你自己操作，我给了现成 SQL）
1. 打开 [schema.sql](F:\拼豆图转化器\supabase\schema.sql) 全选复制；
2. Supabase 左侧 **SQL Editor** → New query → 粘贴 → Run。

### 3. 部署激活校验函数（防激活码泄密的关键）
1. 打开 [index.ts](F:\拼豆图转化器\supabase\functions\activate\index.ts) 全选复制；
2. Supabase 左侧 **Edge Functions** → Create a new function → 名字填 `activate` → 粘贴保存并 Deploy。

### 4. 生成测试码
```bash
# 在项目目录运行，生成每类 5 个随机激活码（7 天/30 天/90 天/永久）
dart run tools/gen_trial_codes.dart 5
```
把输出的 SQL 贴到 Supabase SQL Editor 执行，得到码列表发给测试用户。

### 5. 打包试用版
```bash
powershell -ExecutionPolicy Bypass -File tools\build_apk.ps1 -Trial `
  -SupabaseUrl https://你的项目.supabase.co -SupabaseKey eyJ你的anonkey
```
产出 `豆图试用版_v0.9.2_*.apk`（独立 applicationId `.trial`，可与正式版共存安装）。

### 试用版规则（已实现）
- 新装：24 小时试用（顶部有倒计时条）→ 到期全屏锁定 → 输入激活码解锁；
- 激活码**一次性/限量**（服务器记录，防传播复用）；
- 卸载重装：Android 平台限制无法 100% 识别同一设备（详见 [v0.9-trial.md](F:\拼豆图转化器\docs\plan\v0.9-trial.md)），
  激活码一次性 + 云备份已覆盖常见路径。

## 五、常见问题

| 问题 | 解决 |
|------|------|
| 安装提示"解析包错误/未安装" | 架构选错 → 换 `arm64-v8a`；或 APK 传输损坏 → 重新传 |
| 提示"未安装应用"（覆盖安装失败） | 旧版签名不同？同一渠道发的包签名一致可覆盖；实在不行卸载旧的再装（**会清空本地作品，先备份**） |
| 打开闪退 | 重启手机；仍不行把机型+系统版本发我排查 |
| 颜色/背景不准 | 设置页开「照片去噪/边缘锐化/输入增强」；换预设「细腻」；背景杂用裁剪页「自动提取主体」 |
| 图片变形 | 设置页「📏 图纸比例」打开「保持原图比例」 |

## 六、iOS 用户说明

APK 是安卓格式，iOS 无法直接安装。若需要 iOS 版：
- 需在 **macOS + Xcode** 上构建（项目 `ios/` 已就绪，README 有步骤）；
- 分发走 TestFlight（Apple 开发者账号 $99/年）；
- 或者让 iOS 用户用网页版（如已部署 <https://15209896293.github.io/doutu/app/>，注意是旧版构建，需重新构建 web 产物同步）。
