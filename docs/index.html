豆图 · 拼豆图纸转化器

把照片变成可上手的拼豆图纸 —— 色号准确 · 本地优先 · 完全免费
免费 · 无广告 · 无内购 图片不上传 纯本地处理 非商用开源

✨ 功能

🎨

精准色卡映射

CIEDE2000 色差算法 + KD-tree 加速，4 套色卡（MARD / Perler / Hama）

✂️

自动提取主体

背景太乱？一键自动框出图片主体，再手动微调

🔍

图纸预览

色号数字标注 + 图例式用量清单 + 原图对比 + 成品模拟

📦

库存 / 套盒匹配

录入你手头的豆子，生成时提示还缺哪些色、缺几颗

🧵

数字填色跟做

每格标编号、点格打勾，进度自动保存，拼一半也能续

📤

导出分享

高清 PNG / PDF（图纸+用量清单）导出，微信小红书直接分享

🎬

新手引导

点对点 coach marks，一步步带你上手

🛡️

隐私优先

图片与数据只在你的设备本地，不上传任何服务器

📲 获取

当前为 Flutter 移动应用（Android / iOS）。最新 APK 已发布到 GitHub Releases， 主流手机选 arm64 包即可。

🌐 网页版试用（免安装） 下载 APK GitHub 源码

网页版数据保存在浏览器本地（localStorage），换设备/清缓存会清空作品；完整体验建议用手机 App。

安装时需允许「安装未知来源应用」；安装包为 debug 签名，仅用于个人试用。
