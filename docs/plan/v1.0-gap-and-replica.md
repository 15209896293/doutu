# v1.0 差距分析与 pixel-beads.com 复刻计划

> 目标：对照 pixel-beads.com（已源码级逆向）找出我们软件的差距，
> 把其关键技术复刻到本软件。用户反馈的痛点：**比例被压成正方形导致还原度差、图纸质量一般**。

---

## 1. 核心差距（按用户痛点排序）

### 1.1 🔴 非正方形网格（比例变形）——用户最痛的点

| | pixel-beads.com | 我们 |
|---|---|---|
| 网格 | **宽度固定（10–200），高度按原图宽高比自动**（N×M 矩形） | 全部正方形板型（29/52/81/128），**4:3/16:9 的图被压成正方形** |
| 宽度预设 | 52 / 104 / 自定义 | 无（只有板型） |
| 单边上限 | 200 颗 | 256 |
| 圆形板 | 无 | 有（29 圆形） |

**根因**：`BoardPreset` 只有正方形；转换管线 `gridSize` 是单一 N。
**复刻**：ConvertOptions 增加 `gridHeight`（null=按原图比例自动）；Pattern 增加 `height`；
采样/选色/后处理/渲染全部支持 W×H。

### 1.2 🟠 分析图超采样与还原度

| | pixel-beads.com | 我们 |
|---|---|---|
| 分析图 | `analysisPixelsPerCell=4`（每格 4 分析像素），单边 ≤1024，**按网格宽高比** | `clamp(grid*4, 64, 1024)`，正方形，比例跟随网格（改为 W×H 后等效） |
| 采样 | dominant-bucket（4~5bit） | dominant-bucket（3~5bit，默认 4）✅ |
| 轮廓处理 | darkRatio+contrast 双条件 | ✅ 已复刻 |
| 选色 | fixed-palette-greedy / cluster-then-snap | ✅ 已复刻 |
| 色差 | OKLab / CIEDE2000 | ✅ 已复刻 |
| 抖动 | RGB 蛇形 FS（仅 detailed） | ✅ 已复刻 |
| 正则化/清理 | ✅ | ✅ |

> 还原度算法层已基本对齐（v0.8），**比例变形是还原度差的主因**；
> 修复 1.1 后还原度将显著提升。

### 1.3 🟡 色号子集选择

pixel-beads 提供 MARD 24/48/72/96/120/144/221/291 分级子集；我们只有 4 套完整色卡。
子集划分需要数据依据（官方 221 基础 + 扩展），列为待办。

### 1.4 🟡 网格辅助线与导出样式

- 辅助网格：每 5/10 格辅助线、坐标标注（我们有网格线，无坐标/辅助线分级）
- 导出：pixel-beads PDF 支持 Symbols/Letters/Numbers/彩色框 多种样式 + Excel；
  我们只有 PNG/PDF 数字版
- 网格大小 5mm/2.6mm（影响成品尺寸换算，我们导出按格数不按 mm）

### 1.5 🟡 编辑增强

- pixel-beads：图层、对称轴、手动绘制
- 我们：画笔/橡皮/取色/填充/替换/镜像翻转（无图层/对称轴/手绘）

### 1.6 🟢 已对齐（无需复刻）

- 四档风格预设（简化/标准/细腻/平滑）✅
- 色号排除/恢复 + 自动重映射 ✅
- 诊断信息（背景置信度/平均ΔE/杂色）✅
- 背景双阈值移除 + 置信度 + 前景把关 ✅
- 用豆清单 + 库存匹配 ✅
- 本地优先（pixel-beads 浏览器本地，我们本地优先，优于它）✅

## 3. 本轮验收

- 4:3 / 16:9 / 竖图转换后图纸**宽高比与原图一致**（不再压成正方形）
- 矩形图纸在预览/编辑器/跟做/导出全链路正常
- 原有正方形板型（含圆形板）不受影响
- `flutter test` 全绿；quality_check 达标
