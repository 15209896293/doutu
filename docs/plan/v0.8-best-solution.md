# v0.8 最优解方案：效果优先 + 集成度优先（定稿）

> 依据：v0.7 的根因拆解 + pixel-beads.com 源码级还原 + 主流拼豆软件调研。
> 目标：一套**效果最优**（色差最小、背景最干净、毛边消失）且**软件集成度最优**
> （参数收敛为预设、诊断透明、色号排除、编辑/导出闭环）的实现方案。
> 原则不变：纯 Dart、无新原生依赖、Isolate 执行、本地优先。

---

## 0. TL;DR

- **色差**：三个动作一次到位——① 映射源从「区域均值」改「**dominant-bucket 众数采样**」；
  ② 新增**贪心最大覆盖选色**（fixed-palette-greedy，替代按用量留 top-K）；
  ③ 色差距离抽象为 **OKLab（默认）/ CIEDE2000** + 红色主导防御 + 可选加权。
- **背景误识别**：背景检测移到**映射前、像素级**，用**双阈值 flood-fill（种子 ΔE8 / 填充 ΔE13~14）+
  前景覆盖率把关（≥0.15）+ 置信度门槛（≥0.85）**；映射前直接标记背景格。
- **灰色毛边**：采样阶段做**轮廓检测**（暗占比 + 对比度），轮廓格取**暗像素均值**并打 isOutline 标记，
  贯穿整条管线（抖动/清理/正则化全部跳过轮廓格）。
- **集成**：4 档预设收敛参数；预览给「去背景蒙层」；诊断数据（背景置信度/平均映射色差/稀有色数）直接展示；
  用量清单支持**色号排除/恢复 + 自定义色**；补**镜像翻转**；色卡升级为官方数据 + 实物校色管线。

## 1. 效果最优解：算法管线定稿

### 1.1 管线总览（对照现状的 diff）

```
现状：解码 → 区域均值采样 → CIEDE2000 直接映射全色卡 → FS抖动(Lab) → 面积阈值合并
      → 映射后 flood-fill 去背景(ΔE4) → top-K 削色 → BOM

定稿：解码 → ①分析画布降采样(≤1024, 每格4分析像素)
     → ②像素级背景检测(双阈值+置信度+前景覆盖率)【新】→ mask
     → ③每格 dominant-bucket 采样 + 覆盖度 + 轮廓检测【改】→ cells(含isOutline)
     → ④贪心最大覆盖选色 fixed-palette-greedy【新】→ 选中色号子集
     → ⑤映射到选中色号(OKLab默认/CIEDE2000可选)【改】
     → ⑥FS抖动(RGB蛇形, 跳过背景/轮廓)【改】
     → ⑦空间正则化(边缘保护, 1~2迭代)【新】
     → ⑧多数表决清理(8邻域≥4, 跳过轮廓)【改】
     → ⑨BOM + 诊断数据【新】
```

### 1.2 模块清单与接口（纯 Dart）

| 模块 | 文件 | 职责 | 关键接口 |
|------|------|------|----------|
| 采样+轮廓 | `sampler.dart`（改） | dominant-bucket、重叠/alpha 加权、前景覆盖度、轮廓检测 | `SampleCell {rgb, coverage, isOutline, darkRatio, luminanceRange}`；`SamplerOptions{cellSamplingMode, colorBucketBits, outlineDarkLuminance, outlineDarkRatio, outlineContrast, minimumForegroundCoverage}` |
| 背景检测 | `background_remover.dart`（新） | 像素级边界中位数锚点、置信度、双阈值 flood-fill | `detectBackground(image, {seedDeltaE=8, fillDeltaE=14, minConfidence=.85, minForegroundCoverage=.15}) → BackgroundMask{bitmap, detected, confidence}` |
| 色差 | `color_mapper.dart`（改）+ `oklab.dart`（新） | 距离抽象 OKLab/CIEDE2000；红色主导防御；加权选项 | `enum ColorDistance {oklab, ciede2000, weightedLab}`；`mapper.nearestIndex(lab, distance)` |
| 选色 | `palette_selector.dart`（新） | 贪心最大覆盖选色（≤maxColors）；cluster-then-snap（加权 k-means 兜底） | `selectPaletteSubset(cells, palette, maxColors, distance) → List<int> selectedIndices` + `mapCellsToSelected(...)`；同时返回 `meanMappingDistance` |
| 后处理 | `post_processor.dart`（改） | 空间正则化（边缘保护）；多数表决清理 | `regularize(grid, cells, {iterations, smoothness, edgeSigma})`；`cleanupByNeighbors(grid, minNeighbors)` |
| 抖动 | `pattern_converter.dart`（改） | RGB 蛇形 FS，跳过背景/轮廓格 | 复用现有 FS 权重，改 RGB 空间 + 跳过标记 |
| 主管线 | `pattern_converter.dart`（改） | 组装上述顺序；输出诊断 | `ConvertResult{pattern, avgColors, diagnostics}` |

### 1.3 预设参数（4 档，收敛 UI）

| 参数 | 精简 | 标准（默认） | 细腻 | 平滑自然 |
|------|------|--------------|------|----------|
| 采样 | dominant-bucket(4bit) | dominant-bucket(4bit) | dominant-bucket(5bit) | average |
| 色差 | oklab | oklab | ciede2000 | oklab |
| 选色 | fixed-greedy | fixed-greedy | fixed-greedy | cluster-then-snap |
| maxColors | 8 | 0（不限，UI 可调） | 16 | 0 |
| 抖动 | 关 | 开（轻） | floyd-steinberg | floyd-steinberg |
| 背景检测 | 开(0.85/13) | 开(0.85/14) | 开(0.88/13) | 开(0.85/14) |
| 正则化 | 2/3/8 | 2/2/10 | 1/1/12 | 关 |
| 清理 | 4 | 5 | 7 | 关 |
| 轮廓处理 | 开 | 开 | 开 | 关 |

> 预设仅收敛默认值，高级参数面板仍可逐项覆盖（保留现有「专家模式」）。

### 1.4 性能预算（Isolate）

- 分析画布 ≤1024px（`analysisPixelsPerCell=4`，128 板 → 512px 分析画布足够）；
- 贪心选色 O(不同色 × 色卡数) ≈ 数千次距离计算，128×128 全链路目标 ≤300ms（真机）；
- 沿用 `convert_isolate.dart`，UI 零阻塞；大图防御降采样保留。

## 2. 软件集成度最优解：功能与 UX

### 2.1 预设选择（setup_screen）
- 「图案细节」四档预设 chips（精简/标准/细腻/平滑自然），选择即应用参数组并记忆；
- 高级参数折叠展开，仍可微调（色数上限/抖动/去背景/色差档位）。

### 2.2 背景蒙层预览（preview_screen）
- 「原图对比」视图叠加**将被移除区域蒙层**（棋盘格/半透明），生成前即可见「背景会不会被去掉」；
- 蒙层来自背景检测的 mask，直接复用 `ConvertResult.diagnostics`。

### 2.3 诊断信息展示（preview_screen）
- 生成结果下方展示：`背景已移除（置信度 92%）/ 未检测到背景`、`使用 23 色`、
  `平均映射色差 ΔE 1.8`、`稀有色 3 个 / 孤立单格 5 个`（提示可开「细腻」或调预设）；
- 对应 pixel-beads 的 `backgroundConfidence / meanMappingDistance / rareColorCount / singleCellRegionCount`。

### 2.4 色号排除/恢复 + 自定义色（preview_screen + editor）
- 「用量清单」每条色号加排除/恢复按钮；排除后自动重映射到「已存在且未排除」的最近色
  （复用 `palette_selector` 的映射函数）；
- 支持直接输入 hex 覆盖某个色号（对齐 pixel-beads 的 color input）。

### 2.5 镜像翻转（editor/preview）
- 一键水平翻转图纸（熨烫「摆反图、烫正图」刚需，`拼豆制图师` 同款）。

### 2.6 色卡数据（palettes/ + tools/）
- 数据源升级：Perler/Hama 官方 chart、**新增 Artkal**、MARD 官方 168 色整理；
- `PaletteEntry` 加 `source/version` 标注；`calibrate_palette.py` 实物校色管线保留并纳入发布流程；
- README 增加色卡来源与版本说明（用户信任资产）。

### 2.7 编辑/导出闭环（已有能力补齐联动）
- 编辑器现有画笔/橡皮/取色/填充/替换，补充：编辑后 BOM 与用量清单实时重算；
- 导出保持高清 PNG/PDF；PDF 增加「预设与参数」水印行（记录生成参数，便于复现）。

## 4. 验收标准（量化）

1. 输出图纸**无 <2 格孤立杂色**、无灰色毛边（10 张样本目检）。
2. 简单背景（纯色/渐变/双色）**背景移除成功率 ≥90%**；主体铺满图不误删（回归集断言）。
3. 相同色数上限下，**平均映射色差（ΔE）较 v0.6 下降 ≥15%**。
4. 128×128 转换 **≤300ms**（Isolate，真机中端）；UI 无阻塞。
5. 色号排除/恢复、镜像翻转、背景蒙层、诊断展示四项 UX 手测全通。
6. 色卡数据带来源/版本；Perler/Hama/MARD/Artkal 四品牌可用；`flutter analyze` + `flutter test` 全绿。

## 7. 修复记录（用户反馈"有时整图变空白"）

**现象**：部分图片转换后输出大片空白。

**根因（已复现，3 场景有效格 0/1600）**：
1. 背景 flood-fill 用松阈值（ΔE 14），主体与背景色差 <14（白主体+米白背景、
   同色系浅色主体+背景）时主体被整块吞掉；
2. `detectBackground` 没有前景占比把关——吞掉 100% 也照样返回"检测成功"；
3. `convertImage` 对"有效格为 0"无兜底，直接输出全透明网格。

**修复**：
1. `background_remover.dart`：flood 后**前景占比把关**（<5% → 紧档 fillDeltaE÷1.6 重试一次，
   仍不足 → 放弃移除），主体≈背景色时不再吞主体；
2. `pattern_converter.dart`：兜底①有效格 <5% → **去掉背景重采样**（绝不输出空白）；
   兜底②去掉背景后仍 <2% → **友好报错**（提示换图/先裁剪）；
3. `ConvertDiagnostics.backgroundFallback`：预览页橙色横幅提示
   「⚠️ 背景与主体颜色相近，已保留原图」。

**验证**：`tools/repro_blank.dart` 三个风险场景有效格 100%；
quality_check 正常场景（渐变/双色背景）移除率仍 100%；
`flutter test` 119 全绿（新增 5 个空白兜底用例）。
