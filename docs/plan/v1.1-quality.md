# v1.1 转换质量提升方案（主流软件技术调研）

> 用户反馈「转换质量很低」。综合调研主流工具（pixel-beads / BeadPattern / bitbead 比特拼豆 /
> pypindou / PixelOE / photo2pixel / 鸿蒙系列实践），列出可落地的质量提升技术。

---

## 1. 主流软件的质量提升技术（调研结论）

| 技术 | 代表 | 说明 | 我们现状 |
|------|------|------|----------|
| **输入预滤波**（转换前去噪/增强） | pypindou `prefilter="smooth"`；photo2pixel kernel_size | 照片降噪 → dominant-bucket 更准、色块更净；适度对比度/饱和度增强让颜色更鲜明 | ❌ 完全没有 |
| **小区域合并** | pypindou `min_region_size=2..4` | 面积 ≤N 格的连通域并入相邻主色 → 图纸更干净、利于手工摆豆 | ⚠️ 只合并 1 格（removeSingleCellRegions） |
| **对比度感知轮廓扩展** | PixelOE（SIGGRAPH 级） | 灰度局部中位数 → 权重图 → 选择性膨胀/腐蚀 → 高对比边缘在降采样后存活 | ⚠️ 仅轮廓识别（isOutline），无扩展/锐化 |
| **对比度感知降采样** | PixelOE（LAB 通道滑动窗口，偏暗取暗值） | 自适应选代表像素，保留明暗细节 | ⚠️ dominant-bucket 众数桶（已较好，可加明暗偏好） |
| **色差三档** | bitbead（RGB 快速 / CIE94 标准 / CIEDE2000 高质） | 质量/速度分级 | ⚠️ 有 OKLab/CIEDE2000（OKLab 已优于 CIE94） |
| **unidentified 色号过滤** | pypindou | 不可靠色号默认排除 | ❌ 无（色卡质量尚可，低优先） |
| **AI 抠图/主体增强** | Linux DO / V2EX 多模态大模型方案 | 质量天花板最高（识别主体、去背景、构图） | ❌ 无（需后端/LLM，违背本地优先，远期可选项） |
| **参数建议** | pypindou | 照片 max_colors=16..48 + smooth 预滤波 + majority 清理 + min_region 2..4；**抖动不适合默认** | ✅ 基本符合（默认无抖动） |

## 2. 实施记录（v0.9.1 / v0.9.2）

| 项 | 版本 | 说明 |
|----|------|------|
| **A. 输入预滤波** | 0.9.1 | `prefilterSmooth`（保边去噪 `smooth(weight:3)`）+ `prefilterEnhance`（contrast 1.08/saturation 1.05） |
| **B. 小区域合并** | 0.9.1 | `minRegionSize`（默认 3，标准/精简/细腻档；平滑档 1） |
| C. 高级参数 UI | 0.9.1 | 「照片去噪」「输入增强」「边缘锐化」三个开关 |
| **D. 边缘锐化** | 0.9.2 | `prefilterSharpen`（unsharp mask，amount 0.45），卡通/描边图边缘更清晰 |
| **E. 辅助网格分级线** | 0.9.2 | 预览/导出/编辑器/跟做画布：细线 + 每 5 格中粗 + 每 10 格大粗 |
| F. 参数序列化 | 0.9.2 | 新参数进作品 JSON（保存/恢复不丢失） |
| G. 色号子集 | — | 跳过：贪心最大覆盖选色已等效"动态子集"，且官方子集数据缺失 |
| H. 对比度感知轮廓扩展（PixelOE 完整版） | — | 未做：unsharp 锐化 + isOutline 暗像素均值已覆盖主要收益；完整形态学膨胀收益有限、成本高 |

> 实测结论：预滤波对**合成高对比图有害**（边界模糊），故默认关闭、照片用户按需开启（与 pypindou 一致）。

## 3. 待办（工作量/价值权衡后延后）

- 对比度感知轮廓扩展（PixelOE，中等工作量，可做轻量版：分析图 unsharp/smooth(weight>4) 锐化边缘）
- 明暗偏好采样（低收益）
- AI 抠图（需后端，远期）
- unidentified 过滤（低优先）

## 4. 验收

- 带噪点照片：预滤波后孤立杂色减少、主色更净
- minRegionSize=3：≤3 格小色块并入相邻主色（图纸更干净），≥4 格细节保留
- `flutter test` 全绿、quality_check 达标
