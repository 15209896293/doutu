## 01 需求洞察：用户到底要什么（2026 调研）

综合应用商店评价、小红书反馈与竞品功能，当前拼豆转化类用户的真实需求排序：

| 优先级 | 需求 | 证据 |
|--------|------|------|
| P0 | **色号准确、色差小** | [颂拼豆使用体验（小红书）](https://www.xiaohongshu.com/discovery/item/6915ef770000000004028c91)：用户点名"色号匹配偶尔有色差"；转化工具的第一信任资产 |
| P0 | **出图快、操作不中断** | [被用户吐槽后，我连夜优化了这个拼豆小工具（腾讯云）](https://cloud.tencent.com.cn/developer/article/2715002#1)：大图/长流程是流失重灾区 |
| P1 | **数字填色/照着摆** | [拼豆豆（App Store）](https://apps.apple.com/cn/app/%E6%8B%BC%E8%B1%86%E8%B1%86-%E6%8B%BC%E8%B1%86%E5%9B%BE%E7%BA%B8%E7%94%9F%E6%88%90%E5%99%A8-%E5%83%8F%E7%B4%A0%E6%95%B0%E5%AD%97%E5%A1%AB%E8%89%B2%E5%8A%A9%E6%89%8B-%E5%9B%BE%E6%A1%88%E8%AE%BE%E8%AE%A1%E7%A5%9E%E5%99%A8/id6761741272)：主打"像素数字填色助手"，说明该形态是刚需 |
| P1 | **套盒/库存匹配** | 颂拼豆"精准匹配个人套盒"被夸为超实用功能，是强留存点 |
| P2 | **社区找图/分享** | 颂拼豆"社区找图/分享超方便"；社区是留存抓手但需要后端投入 |
| P2 | **AI 生成** | [AI豆仓](https://www.gameyj.com/down/45869.html)、[Ai Pin Dou](https://apps.apple.com/ee/app/ai-pin-dou/id6756688364) 已出现，质量存疑，可观察不跟进 |

> 结论：**v0.3 聚焦"质量 + 不中断"**（算法精细度、大图保护、流程闭环），
> 数字填色跟做作为差异化体验一并落地；社区/库存/AI 列为后续候选。

## 02 竞品对比：我们 vs 市场

| 维度 | 颂拼豆 | 拼豆豆 | 拼豆画 | 豆图（我们） |
|------|--------|--------|--------|-------------|
| 色卡映射 | 有（偶有色差） | 有 | 有 | **CIEDE2000 + KD-tree，已过官方测试数据验证** |
| 本地优先 | 部分联网 | 本地 | 本地 | **纯本地，图片不上传（隐私卖点）** |
| 套盒/库存 | ✅ | ❌ | ❌ | ❌（P2 候选） |
| 数字填色跟做 | 弱 | ✅ 主打 | 弱 | **v0.3 全新落地（点格打勾+图例高亮）** |
| 新手引导 | 弱 | 弱 | 弱 | **v0.3 磨砂玻璃 product tour** |
| 大图保护 | 一般 | 一般 | 一般 | **v0.3 预检 + 兜底提示** |
| 变现 | 免费+内购 | 免费 | 免费 | **完全免费无广告** |

**v0.3 差异化组合**：精准算法 + 数字填色跟做 + 本地隐私 + 新手引导。
这四件事同时做好的工具目前市场上没有明显竞品。

## 03 现状诊断：7 条反馈的根因与修复

| # | 反馈 | 根因（代码级） | v0.3 修复 |
|---|------|----------------|-----------|
| ① | 大图/大文件无法分析 | 选图后无尺寸/体积预检，直接解码；生成失败只显示生硬报错 | 选图即轻量预检（`findDecoderForData` 读头）+ 超限弹窗引导裁剪；生成失败映射为友好提示；转换器内防御性降采样兜底 |
| ② | 转换太粗糙 | 抖动默认关闭（Bayer 抖动仅扰动不传播误差）；映射源用"众数投票"糊细节；默认 52×52 偏粗 | 映射源改**区域平均色**；抖动改**Floyd–Steinberg Lab 误差扩散**并默认开启；新增 **128×128 板型**、默认板型 **81×81** |
| ③ | 预览/设置/导出没有返回 | 流程用 `context.go` 替换路由栈，无返回键；导出无首页入口 | 关键步骤改 `push`（保留系统返回）+ 显式"返回上一步"按钮；导出加"首页"按钮 |
| ④ | 保存的作品无法查看 | **真 bug**：预览/编辑/跟做/导出读全局 `conversionProvider`，完全忽略路由传入的作品对象；且色卡按"当前设置"解析而非作品记录的色卡 | 新增 `openProject()` 把作品载入转换状态；新增 `paletteForPatternProvider` 按 `pattern.paletteId` 解析色卡；历史/最近作品入口先 load 再跳转 |
| ⑤ | 数字标注/清单默认开启 + 清单在图标下 | `_showCodes`/`_showBom` 默认 false；BOM 是右侧浮层 | 默认开启，点击图标切换；BOM 改为**图纸下方图例式**（色块图标下方标颗数），新增 `BomLegend` |
| ⑥ | 跟做环节没用 | 逐色高亮：不标数字、无分区、推进感弱 | 重构为**数字填色**：每格标编号 + 底部图例（编号↔色号↔进度）+ 点格打勾 + 点图例高亮剩余格 |
| ⑦ | 缺新手引导 | 无任何 onboarding | 新增磨砂玻璃质感 `ProductTour`：BackdropFilter 模糊 + 半透明玻璃卡片，7 步讲全流程；首次启动自动播放（`tourSeen` 持久化），设置页可重看 |

## 05 产品迭代路线图

| 版本 | 目标 | 核心内容 | 状态 |
|------|------|----------|------|
| v0.1 | MVP 可跑通 | 导入→裁剪→设置→生成→预览→导出 | ✅ 已交付（用户反馈 7 条） |
| v0.2 | 功能完整 | 编辑器/跟做/历史/高级参数 | ✅ 已交付 |
| **v0.3** | **质量 + 闭环 + 引导** | 7 条反馈全部落地（见 §03） | 🚧 本次 |
| v0.4 | 留存与调优 | 库存/套盒匹配、跟做进度持久化、参数记忆、算法按真实图片调参、埋点（安装/转化/导出率） | 待排期 |
| v1.0 | 上架 | 双端商店 + ICP 备案 + 冷启动内容 | 待排期 |

**v0.4 候选（按投入产出排序）**：
1. **套盒匹配/库存管理**（P2 高价值）：让用户录入已有豆盒，生成时提示缺口 —— 竞品已验证的强需求。
2. **跟做进度持久化**：`_done` 现在仅内存态，退出即丢；存进 Project 可让"拼一半"的作品续拼。
3. **参数记忆**：板型/色卡/高级参数记入 settings 并真正接入转换流程（当前 settings 里 `dither/maxColors` 未接线）。
4. **算法调参**：用真实手机相册图回归测试，校准 `backgroundDeltaE` 与误差扩散强度。
5. **埋点**：转换完成率/导出率，指导下一轮。

## 06 质量与验证

| 项 | 方法 |
|----|------|

## 07 风险登记（v0.3 增量）

| 风险 | 对策 |
|------|------|
| 误差扩散默认开启可能让"纯色像素画"出现细颗粒 | 平涂图误差≈0 不受影响；高级参数仍可关闭抖动 |
| 默认板型 81 在小屏上格子偏小 | 预览/跟做支持双指缩放（16x）；可一键切回 52 |
| 作品旧 JSON 无 `tourSeen` 等新字段 | fromJson 全部带默认值，向后兼容 |
| 引导覆盖层与导航冲突 | 纯 Overlay 实现，不改变路由；markSeen 持久化失败有兜底 |
